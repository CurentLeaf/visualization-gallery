One fictional dataset. Five visual treatments. One page.

All values are synthetic. Temperature spread is not source reliability. Missing information is not proof of error.

1. Uncertainty — ggdist

Actual R/ggdist output generated during deployment. Thick intervals show central 50%; thin intervals show central 95% of simulated draws. These distributions are assumed, not calibrated from observations.

2. Exploration — Plotly

Hover for report identifiers. Compare estimates with report age; the apparent trend is invented.

3. Custom encoding — D3

Blue bar: relative report age (0–33 hours). Verification and spread stay separate.

An experimental encoding, not a validated trust display.

4. Provenance — Cytoscape.js

Click a node. This illustrative chain establishes origin, not truth or independent corroboration.

5. Missing information — missingno

Filled cells are present; blank cells are absent. Rows follow R-01 through R-12. The image is generated with the actual missingno library.
